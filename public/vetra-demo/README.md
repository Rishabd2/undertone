# careVet clinic demo

Seven-scene walkthrough + always-on Medplum watch for Luna.

```bash
npm run dev
open http://localhost:3000/vetra-demo
```

- **Play** runs scenes 1–7. Behind-the-scenes events link into Luna’s real Medplum resources.
- While a call is writing, new Observations / Appointments / Tasks appear in the right rail automatically (no extra button).
- Original routes (`/`, `/live`, `/clinic`) are unchanged.
